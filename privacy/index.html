Privacy Policy

Last updated: 8th September 2026

1. What data we collect

Tosia collects and stores only the data strictly necessary for the bot's core functions. This includes:

  • Discord User IDs
  • Discord Server (Guild) IDs
  • Channel configurations, e.g., for automated messages

We do not collect, log, or store the content of user messages.

2. Why we collect data

The collected data is used exclusively to operate the bot's features (such as saving user preferences or server-specific configurations). We do not share, sell, or distribute this information to any third parties.

3. Data retention and deletion

Data is kept as long as the bot remains on your server or until it is manually reset. Any user or server administrator has the right to request the complete removal of their data from our database.

To request data deletion, contact @niitosia.
